Multiplication Quiz App 🧮

A simple and interactive web application designed to test and improve multiplication skills. Built using HTML, CSS, and JavaScript, this app generates random multiplication questions and tracks your score in real-time. Users can simply enter their answer in the input field and click submit to check if they are correct. It features a clean, card-based UI with high-contrast colors for easy readability
